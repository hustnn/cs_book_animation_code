## 1. 自检是干什么的

画面上的机械性缺陷——文字被压、骑在框边、互相叠住、出画，动作没播出来，动画早早做完后长时间静止，
动画比旁白长——规则明确、结果可判定，不该靠人一帧帧看。自检分三层：

| 层 | 什么时候 | 工具 | 能拦住的 |
|---|---|---|---|
| 预防 | 写场景时 | `lib/layout.ts`（attach / row / edgePoint）、`beats.ts` 的 `at()` | 让正确的写法成为默认写法，大部分缺陷根本不会出现 |
| 静态检查 | 渲染前 | `lint_scenes.py` | 并行补间冲突、书页/图号/内部编号、两份时间轴不一致、文字卡和超宽 |
| 渲染检查 | 渲染时 | `render.mjs --qa`（`lib/qa.ts`） | 文字被压、被线穿过、骑边、互叠、出画；标签先于它说明的对象出现（orphan）；动画超过旁白（overrun）；动画做完后静止过久（idle） |
| 实测 | 渲染后 | `sample_frames.py` | 每拍抽帧供人看；freezedetect 测画面真实定格 |

规则都按“与具体教材无关的视觉规则”写，靠第 6 节的测试用例保证这一点。

## 2. 十类常见缺陷：成因与预防写法

| 类 | 缺陷 | 成因 | 预防写法 | 谁来查 |
|---|---|---|---|---|
| A | 会长大/移动的图形扫过别人的文字 | 按绝对坐标摆标签，没按图形**终态**留位置 | 标签挂在它描述的图形边上：`attach(label, bar, 'right')`，图形长到哪标签跟到哪；生长的图形要有自己的通道（终态范围内不放别的文字） | QA covered / edge |
| B | 标签没挂在它描述的对象上 | 借用别的组的坐标摆位，结果离错误的对象更近，还可能压边、读错意思 | `attach(label, subject, side)`；分镜里写清每个标签说明的是哪个对象 | QA edge；语义审 |
| C | 一排元素互相叠住 | 手算间距小于元素尺寸 | `row(n, size, gap, center)` / `column(...)` 由尺寸推间距 | QA covered / text-overlap |
| D | 旧元素没退场，新元素占了同一位置 | 同一组里先后演两个例子，前一个的元素一直留着 | 新例子进场的同一拍里让旧例子退场（opacity → 0 或移开） | QA covered / text-overlap |
| E | 文字骑在容器边框上 | 文字贴着容器边摆，没有内边距 | `attach(text, container, side, padding, true)` 放在容器内侧 | QA edge |
| F | 运动的小点停在文字上 | 停靠点取了节点中心（字就在中心） | 停靠点用 `edgePointIn(dot, node, side, gap)`，停在节点旁边 | QA covered |
| G | 动作根本没播出来 | 同一属性在一组并行动画里补间两次（`all(…)`、`sequence(0, …)`） | 要先后发生用 `chain(…)`；往返、脉动用 `.to(…)` | lint |
| H | 动作挤在拍首，之后长时间静止 | 一拍里几个动作并行一次做完，没跟着旁白展开 | `beat(id, at('词1', a), at('词2', b))`：旁白念到哪个词，哪个动作开始；拍首先出整体（空框、轮廓、总标签）再往里填，不留空画面；或者加一段铺满整拍的慢动作 | QA idle；freezedetect |
| I | 有意的遮挡被当成缺陷 | 划掉、打叉、遮罩本来就要盖住文字 | 背景色填充或大面积的遮罩自动识别；划线、打叉的节点设 `key="qa-ignore-<说明>"` | — |
| J | 标签先于它说明的对象出现，或对象退场后标签还留着 | 动作改成跟着旁白分步出现（`at()`）后，标签还在拍首一起淡入，旁边空着；或者对象淡出了、标签没跟着淡出 | 标签和对象放进同一个 `at()` / 同一个 `all()` 一起出现、一起退场；标签用 `attach` 挂到对象上（QA 才知道它说明的是谁） | QA orphan |

## 3. 检查规则：每条在查什么、阈值为什么是这个值

阈值都在 `lib/qa.ts` 的 `QA_CONFIG` 里，工程可以在 `project.ts` 里设 `globalThis.__MC_QA_CONFIG__` 覆盖。

### 渲染 QA（每拍 5 个采样时刻：拍首 +0.15s、25%、50%、75%、拍末 −0.15s）

| 类型 | 判 error 的条件 | 为什么 |
|---|---|---|
| `covered` | 有填充的图形画在文字**之上**，盖住文字框 ≥ `coverMin`（2%） | 文字被挡住就读不全；2% 以下多是抗锯齿、描边外扩带来的贴边 |
| `crossed` | 线（Line、曲线）从文字框中间穿过 | 线穿过字形读起来像被划掉；线若在托住文字的不透明卡片下面则看不见，不算 |
| `edge` | 文字框落在图形里的比例在 [`edgeMin`, `insideMax`) = [10%, 90%) | 文字骑在边上像摆错了位置；≥ 90% 算在里面（矩形文字框放进圆里四角总会探出一点） |
| `text-overlap` | 两段文字重叠 ≥ `overlapMin`（较小那段的 15%） | 两段字叠在一起都读不清 |
| `offscreen` | 文字框超出画面 | 观众看不到 |
| `overrun` | 一拍的动画比旁白长 | 画面被顺延，后面每一拍都和配音错位 |
| `idle` | 动画做完后这一拍还要静止 ≥ `idleError`（6s）；3–6s 为 warn | 旁白在讲、画面不动太久，观众会以为卡住；与 skill 的“单次静止 ≤ 6s”门槛一致 |
| `orphan` | 用 `attach` 挂上的标签已经看得清（不透明度 ≥ `solid`），它说明的对象却透明或宽/高 < `subjectMin`（1px） | 标签旁边空着，观众不知道它在说什么；“更长”出现在红条之前，就是在说一个还不存在的东西。只查 `attach` 挂上的标签：手摆的标签 QA 不知道它说明的是谁 |

几何按“在图形自身坐标系里，用文字四边形和图形轮廓求精确交集”算（圆按 32 边形），旋转、缩放、offset 都不影响。

### 降为 warn 的情况（仍会列出，供看联系表时扫一眼）

| 情况 | 条件 | 为什么不算 error |
|---|---|---|
| 转场叠化 | 文字或图形的不透明度 < `solid`（0.6） | 旧画面淡出、新画面淡入时短暂重叠是设计 |
| 半透明高亮 | 压在文字上的填充实际不透明度 < `translucent`（0.5） | 文字仍看得清 |
| 遮罩层 | 用画面背景色填充，或面积 ≥ 画面的 `maskArea`（50%） | 雾、暗场、擦除本来就要挡住下面的内容 |
| 瞬时 | 同一对元素重叠的采样点 < `minSamples`（2） | 元素正在飞入、散开、穿过；“同一对”按节点身份判断，正在变长的柱子压字算持续问题 |

### 静态 lint

| 检查 | 条件 | 为什么 |
|---|---|---|
| 并行补间冲突 | 同一 `ref().属性` 在一组 `all(…)` / `sequence(0, …)` 里出现两次 | 两个补间同一帧互相覆盖；抽出的任何一帧都看着正常，人工复审很难发现 |
| 观众可见文字 | 画面文字和旁白里出现书页、图号、“书里/原书/本书/原图/原表”、Part、内部编号（U3、b27） | 动画要自包含，观众手边没有书；“p6”这类记 warn（p50/p99 等百分位不算） |
| 时间轴副本 | 场景 import 的 timeline 与章节目录里那份不一致 | 渲染会静默用旧时长 |

## 4. 自检循环：每个场景写完怎么走

```
写场景（用 attach / row / edgePointIn / at 写）
  → npx tsc --noEmit
  → lint_scenes.py --timeline-dir … --narration …       有 FAIL → 按第 5 节修 → 回到 lint
  → render.mjs <场景> --qa                               有 error → 按第 5 节修 → 重渲
  → sample_frames.py <视频> --timeline … --scene …      看联系表；定格 ≥ 6s 的拍要改
  → 自检全部通过，才进入人工的四道审查
```

- 每条 QA error 只有两种结局：**修掉**，或者确认是有意效果、给节点设 `qa-ignore-<说明>` key。不要通过调大阈值让它消失。
- 修完一定重跑：修一处可能引入另一处（例如把动作改成跟着旁白开始后，动画反而超过了旁白——overrun 会报出来）。
- 自检结果（lint 摘要、QA 的 error/warn 数、定格超标的拍）记进本轮 `review.md`。

## 5. 修复手册：报告里的每类发现怎么修

| 发现 | 先判断 | 常见修法 |
|---|---|---|
| `covered`（图形压字） | 图形是在长大/移动吗（类 A）？是旧例子没退场吗（类 D）？是有意遮罩吗（类 I）？ | A：标签 `attach` 到图形边上，或给图形留通道（挪开文字、缩小终态）；D：同一拍让旧元素退场；I：划线/打叉设 `qa-ignore` key |
| `edge`（文字骑边） | 文字是不是贴着容器边（类 E），或借了别的对象的坐标（类 B）？ | `attach(text, container, side, padding, true)` 放内侧，或 `attach(label, subject, side)` 挂到它说明的对象旁 |
| `text-overlap` | 两段字是同一位置的新旧例子（D），还是一排元素太挤（C）？ | D：旧的退场；C：`row()` / `column()` |
| `crossed` | 线是箭头/连线（要改路线），还是有意划掉（I）？ | 连线绕开文字、或终点停在文字框外；有意划掉设 `qa-ignore` key |
| `offscreen` | 文字太长还是位置太靠边？ | 文字设 `maxWidth` + `textWrap`；位置收进安全区 |
| `overrun` | 是哪个动作太长、或开始得太晚？ | 缩短那个动作；`at()` 的词太靠句尾时改用更早的词或减小时长 |
| `orphan` | 标签是先出来了，还是对象先走了？ | 把标签的淡入放进对象出现的同一个 `at()` / `all()`；对象退场时标签一起退场 |
| `idle` | 这一拍有几个信息点？ | 信息点多：用 `at()` 跟着旁白分步出现；信息点少：加一段铺满整拍的慢动作（如 `node().scale(1.03, beat.dur(id))`） |
| lint 并行冲突 | 想要的是先后还是同时？ | 先后：`chain(…)`；往返/脉动：`a().x(1, d).to(0, d)` |

## 6. 让规则保持通用：测试用例与反馈循环

规则是否通用，不靠在某一章上看结果，而靠一组与教材无关的测试用例：

- `assets/motion-canvas/qa-fixtures/qa-fixture.tsx`：24 拍，每拍一个用例——各类缺陷各自应报 error，
  叠化、半透明、遮罩、瞬时、描边高亮框、旋转卡片、圆里的字、被卡片挡住的线、`qa-ignore` 划线应不报 error，
  用 `attach` / `row` / `edgePointIn` / `at` 的正确写法应干净。期望写在同目录 `expect.json`。
- `assets/motion-canvas/qa-fixtures/lint-fixture.tsx`：lint 的用例（冲突、书页图号、不该误报的百分位和拍号）。
- `scripts/qa_selftest.py --project <motion-canvas 工程>`：把用例临时放进工程渲染、逐条比对，结束后自动清理。

**反馈循环**（在任何一章、任何一本书里发现误报或漏报时）：

1. 在 `qa-fixture.tsx` 里加一拍能复现它的最小用例，在 `expect.json` 写上正确的期望；
2. 跑 `qa_selftest.py`，确认这条用例现在是 FAIL（说明用例真的复现了问题）；
3. 改 `qa.ts` / `lint_scenes.py` 的规则或 `QA_CONFIG` 的阈值；
4. 再跑 `qa_selftest.py`，**全部**用例通过才算改好——新规则不能把以前的用例弄坏；
5. 把新的缺陷类型补进第 2 节的表，必要时在 `layout.ts` 里加一个让它不再发生的写法。

这样规则是沿着“通用视觉规则”演进的，每次修正都留下一个回归用例，而不是按某一章的个案打补丁。
