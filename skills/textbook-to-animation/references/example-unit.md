## 2. 单元 A：“快”到底指什么——响应时间是一个分布

- **钩子：** 同一个接口，你测是 80ms，同事测是 1.2s，谁对？
- **学习目标：** ① 响应时间和延迟有什么区别？② 为什么用百分位、不用平均值？③ p99 = 1s 是什么意思？
- **误区：** 平均值能代表用户体验。
- **核心画面：** 100 个请求的柱状图贯穿全单元（同一份固定种子的数据）。
- **深度演示：** 分布排序（Manim）；1−0.5ⁿ（Manim）。
- **覆盖：** P0 = E3 E4 E5 E7 E8 E9 E11；P1 = E1 E2 E6 E10 E12 E13 E14；P2 = E23（旁白一句带过）。

## 3. 单元 B：尾巴从哪来，又怎么量

- **钩子：** 服务器日志说每个请求都在 50ms 内处理完，用户却等了 3 秒。
- **学习目标：** ① 为什么要在客户端测量？② 压测客户端为什么不能等上一个返回再发？③ 为什么扇出越多越容易慢？④ 为什么不能把各台机器的 p99 取平均？
- **深度演示：** 排队 / 队头阻塞（MC）、闭环 vs 开环（MC）、概率放大 1−0.99ᴺ（Manim）、聚合陷阱（Manim）。
- **覆盖：** P0 = E15 E16 E18；P1 = E17 E19 E20 E22；P2 = E21（旁白一句带过）。

| 拍 | 旁白 | 画面动作 | 屏幕文字 | 要点 | 工具 |
|---|---|---|---|---|---|
| b1 | 服务器说：每个请求我只处理了 50 毫秒。用户说：我等了 3 秒。 | 左边服务器日志全是绿色的 50ms；右边手机转圈 | 50 ms vs 3 s | 钩子 | MC |

## 4. 同一节的两种做法对比

| | 反面做法（按标题切段 + 补文字卡） | 本流程 |
|---|---|---|
| 切分 | 一个小标题一段，缺漏用追加的文字卡补 | 2 个学习单元，每个单元一条叙事弧 |
| 文字卡 | 多数段落是 6–8 行的文字卡 | 0 张（a13 的数字对比卡有旁白配合） |
| 深度演示 | 只演了“取最大值” | 5 个：排序、1−0.5ⁿ、队头阻塞、闭环 vs 开环、1−0.99ᴺ 与直方图合并 |
| 顺序 | 定义 → 示意曲线 → 直方图 → 收尾卡 → “先问两个问题” → … | 跟原书的论证顺序走，开头钩子、结尾回扣 |
| 利用率–延迟曲线 | 用 M/M/1 平均值曲线讲尾部，还标了不存在的“拐点” | 不用；改用队列动画讲同一个道理，讲的是尾部 |
| 时长 | 每段 45s 模板 | 约 4 + 3.5 分钟，由旁白决定 |
