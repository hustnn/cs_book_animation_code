- **流与解码**：ffprobe 确认 h264 1280×720 30fps + AAC 24kHz 单声道 + mov_text 字幕；全片解码 0 错误。
- **单元交界**：8 个交界点前后 0.3s 各抽一帧，平均亮度 24–42，无黑帧（<12），无突兀黑切。
- **收尾句**：9 个单元的收尾拍无重复——每单元以一句不同的“下一单元，……”桥接，下一单元开场即接该钩子；
  U9 收尾“三把尺子收起来。下一章，我们拿着它们去量第一个真正的数据系统。”全章收束。

  恰为 U1 成片时长 264.900s，偏移正确。

- **重叠排查（r2 新增的审查项，2026-11-21）**：每拍中点帧检查文字是否被图形压住——
  逐单元看最终快照成片的每拍中点帧（联系表通览 + 可疑拍全分辨率复核），重点查标签类文字与横条、柱条、
  线、框的重叠。首次执行查出 3 处真实重叠并修进新一轮（U1 b3「原理/实践」标签被横条拦腰截断；
