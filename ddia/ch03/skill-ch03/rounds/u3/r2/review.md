## 新手测试（自测模拟，非独立实测）

方法：制作人自测模拟——只用旁白文本 + 联系表作答，未参考原书；**不是独立实测**（未另开无上下文会话、未找真人）。设计文档学习目标题 3 道 + 误区辨析 2 道，5/5 答对：

| 题 | 回答（凭成片） | 结果 |
|---|---|---|
| 1. SSTable 和日志段有什么区别？ | 日志段按写入顺序排，同一键可出现多次、后写的优先；SSTable 要求按键排好序，合并后每键只出现一次、只留最新值 | 答对（b2a/b2b、b3a/b3b） |
| 2. 稀疏索引是怎么找到键的？ | 内存里只记每隔几 KB 的几个键和偏移；找 handiwork 时先找夹住它的两个已知键（handbag 与 handsome），跳到 handbag 的偏移再往后逐格扫，直到找到 | 答对（b9b、b10a、b10b、b11） |
| 3. 写先进内存、崩溃了怎么办？ | 写先追加进磁盘上的一份日志、再进内存树 memtable；树满几 MB 就刷盘成段；崩溃丢了内存里的最新写，就用日志把内存树恢复出来，刷盘后日志可丢 | 答对（b15a、b15b、b18a、b18c、b18d） |
| 4. 误区：排好序就要在磁盘上原地维护顺序？ | 错。顺序在内存树里排好，刷盘一次写成有序段；磁盘上的段写成后不动，靠后台合并产生新段 | 答对（b14a、b14b、b15b、b17） |
| 5. 误区：查不存在的键和查存在的键一样快？ | 错。查不存在的键要从内存树一路查到最旧的段、每段都可能读一次磁盘才敢说没有；布隆过滤器先问一声，键不在就省掉磁盘读 | 答对（b22a、b22b、b23a、b23b） |
