## 机制口径依据（原书 §3.4 核对 + 扩展注明）

- #24：原书“页引用像指针，但在磁盘上而不在内存里”——主语是**指针/页引用**，旁白改为“页引用存的是磁盘上的地址，不在内存里。”
- #15：原书只说“This algorithm ensures that the tree remains balanced”——父页满了也裂、裂到根长新根是标准 B 树分裂上传机制，作为 3.4-12 的机制展开，非原书原句。

- #17 闩锁：原书“protecting the tree's data structures with latches (lightweight locks)”——“动哪页就锁住哪页，用完就放开”是 B 树闩锁通用做法（短期、按页），作为展开。
- #18 写时复制：原书“a new version of the parent pages in the tree is created”（复数）——“新版本一路传到根（爷爷页、根页都出新版本）”有原书依据；旧页回收（没人读了再回收）与根指针原子切换（LMDB 双元页 + 事务号 + 空闲页表，旧页只在无读者持有该版本时复用）经检索核实。
- #20 分形树：分形树索引论文 [22]（原书引用）——每个内部节点带缓冲，插入先攒进缓冲，攒满一批再往下刷。
- #25 SSD：NAND 擦除块常见 512 KB = 128 × 4 KB 页（一个擦除块通常有五百一十二 KB，是一页的一百二十八倍）。
- #26：原书分支因子定义为“一页中子页引用的个数”——叶页无子页引用，只算内部页。
