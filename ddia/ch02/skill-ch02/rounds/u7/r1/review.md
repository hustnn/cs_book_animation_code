## 6. 新手测试（自测模拟，非独立会话）

本 subagent 无法另开会话，只能以旁白 + 联系表自测模拟。3 道学习目标题（设计里的目标）均可凭本单元内容作答：

1. **map 和 reduce 各做什么？**——map 对每条匹配的文档调用一次，发出键值对（键是年月、值是动物数）；reduce 对每组相同键调用一次，把值加起来，比如 3 加 4 得 7。✅
2. **为什么 map 和 reduce 必须是纯函数？**——只用传进来的数据，不能额外查库、不能改外部世界；这样数据库能在任何地方、任何顺序跑，某台机器失败了重跑一遍就行。✅
3. **为什么说 MongoDB 后来“重新发明了 SQL”？**——2.2 版加了声明式聚合管道，表达力与 SQL 的一个子集差不多，只不过是 JSON 语法而不是英语句子式语法，差别只是品味——换了个新瓶子装 SQL。✅

结果：**3/3（自测模拟）**。第 3 题的答案依赖 b26/b27/b28 三拍，b27 的 6.93s 定格不影响作答，但影响观感（已列 P1 #4）。
